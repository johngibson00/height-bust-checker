# 身長・バスト・男性器 対応チェッカー（公開用 v4）

男性の身長と女性のカップサイズ・乳頭位胸囲・男性器の長さを「それぞれの調査集団内の出現順位」で比較する、非公式の参考計算ツールです。比較は優劣や魅力を意味しません。

- サイト下部に作成者名とXプロフィールへのリンクを表示します。

## 機能
- 身長 ⇄ バスト（カップ数・乳頭位胸囲）／身長 ⇄ 男性器の長さの切り替え
- 男性器の長さは勃起時・通常時（非勃起時）に対応
- 換算結果の下部に、同じ出現順位に相当する各項目の参考値一覧
- 身長・バスト・男性器の測定値はいずれも新しい共有URLのパラメータに含めません（共有文面には結果が含まれます）
- スマートフォンの数値入力とスライダー
- 結果コピー、Web Share API（共有）、X投稿リンク
- 新しい共有リンクは入力値を含まないサイトURLです。結果を共有したい場合は共有テキストに含まれます。入力だけでは自動送信しません。
- CSS / JS / HTML は `index.html` だけに含まれ、外部ライブラリなし。サイト内トラッキングなし。

## プライバシー・履歴について
- 本サイトのコードに、入力数値・計算結果の履歴を保存する仕組みはありません。`localStorage`、Cookie、IndexedDB、外部解析タグ、送信処理などは使用していません。計算は閲覧端末内で実行されます。
- サイト上の案内は **「入力履歴はこのサイトに保存されません」** と表現しています。ブラウザの**ページ閲覧履歴**やホスティング基盤の通常のアクセス記録まで残らないという意味ではありません。ブラウザ独自の入力補完・表示復元もサイトが完全に制御できるわけではありません。
- Xへの共有、端末の共有機能、コピーを利用した場合、画面で表示されていた値や結果が、利用者の操作によって外部のアプリ・相手に渡り、共有先に保存される場合があります。
- 公開用の共有URLはサイトのトップURLのみとし、**入力値をURLに含めない** 仕様です。旧版で発行された結果付きURLは互換性のため読み取りに対応していますが、旧URLに含まれるパラメータには従来のリスクが残ります。
- 第三者製のアクセス解析や追跡コードを追加した場合は、公開前に表示と実装を見直してください。

## GitHub Pagesへの公開手順
1. [GitHub](https://github.com/new) にログインして、`height-bust` などの**公開(Public)**リポジトリを作ります。
2. ZIPを解凍し、**`index.html` を既存のリポジトリ直下の同名ファイルと置き換えてコミット**します。`.nojekyll` は任意です。すでにPagesを設定済みなら設定し直す必要はありません。隠しファイル`.nojekyll` は無くても概ね動きます。
3. リポジトリの **Settings → Pages → Build and deployment → Deploy from a branch** を選び、Branch を `main`、Folder を `/(root)` にして **Save**。
4. 数分〜最大20分程度待つと `https://ユーザー名.github.io/height-bust/` などで閲覧できます。 **Settings → Pages** の `Visit site` を押すと確実です。
5. 公開されたURLをiPhoneのSafariで開き、計算やSNS共有を確認してください。

READMEは説明用で、Web公開には `index.html` と `.nojekyll` のみ必要です。

## データの出典と限界
- 男性身長：厚生労働省「2019年国民健康・栄養調査」20～29歳男性 n=134、平均171.5cm、標準偏差6.6cm。
- カップサイズ：ワコール「からだと下着に関する1万人白書」2011年調査、女性25～54歳、n=10,342、カップサイズは自己申告（区分ごとの回答数から順位を計算）。
- 胸囲：産業技術総合研究所「AIST人体寸法データベース1997–98」青年男性110名（身長）、青年女性107名（乳頭位胸囲）。19～29歳の小規模、東京都の専門学校生標本。
- 男女の指標・調査時期・サンプルの一致は保証されません。結果は厳密な推定や現在の全国分布の代表値ではありません。

- 男性器の長さ：Veale et al. (2015), BJU International. 勃起時n=692、平均13.12cm、標準偏差1.66cm。非勃起時n=10,704、平均9.16cm、標準偏差1.57cm。国際研究の統合値で日本人限定のデータではありません。
- 身長から男性器の実際の長さを予測するものではありません。各集団の順位の換算だけを行います。

**出典詳細はサイト内の「計算方法とデータの注意点」に記載。**
