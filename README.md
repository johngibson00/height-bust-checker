# PERCENTILE LAB v6 — 身長・バスト・男性器の対応表

- 作成者: ゼログラRP / John Gibson（[@JohnGibson18631](https://x.com/JohnGibson18631)）
- 対応: 身長↔カップ数、身長↔乳頭位胸囲、身長↔男性器の長さ、カップ数↔男性器の長さ、乳頭位胸囲↔男性器の長さ（全5通り・双方向）
- 男性器の統計: 日本人対象の研究。勃起時は1981年自己申告調査・1995年発表、通常時は性機能外来患者の医療者実測データ。全国男性の厳密な順位を示すものではありません。
- 本ツールは統計的な参考換算です。異なる身体部位に実際の因果関係や対応関係があるという意味ではありません。
- 入力データはローカル計算のみで、サイト内での保存や外部への自動送信はしません。コピー・共有等は利用者の操作が必要です。
